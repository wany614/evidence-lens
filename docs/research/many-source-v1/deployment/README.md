# CPU deployment and source-bank inspection

The deployment benchmark uses target `h00` in the authored layered-louvers development scene, on the 378 × 252 analysis grid. Coverage-first selection scores the permitted cameras against target-predicted depth and opacity. Ordinary scoring opens the photographs and self-renders in the selected prefix. An operator can separately request a full-library audit to identify comparable evidence outside that prefix. [Prototype and CLI](../../../../prototype/many-source/README.md) · [Study registration](../protocol.md)

The CPU timings distinguish three operations. Fresh-process latency begins just before launching the installed interpreter and ends after the first complete ranking. Source preparation opens the 16 selected source photographs and self-renders in a fresh bank and fills its 128 MiB LRU. A hot repetition reprojects the target, calculates its features and evaluates its rank with the same ordered sources already in memory. It still reads the target prediction. Source selection and bank admission are timed separately and retained in each original receipt.

The representative workload was fixed by the first completed R16 or R128 bank for the development scene. R16 finished first. The pre-fit residual rule used all 16 sources, read 27,130,228 source bytes and scored 95,256 of 95,256 pixels. Its first result arrived 0.496 seconds after launch. Source preparation took 0.0815 seconds. Across seven hot repetitions the median was 0.1581 seconds and the 95th percentile was 0.1602 seconds. Each repetition hit the cache 16 times. Native process RSS reached 235,077,632 bytes and the retained source cache reached 48,779,600 bytes. [Measured pre-fit receipt](prefit.json)

## Importing an external reconstruction

The prepared ETH3D `delivery_area` development bank records 34 source photographs, their 34 same-checkpoint self-renders and ten target predictions in its fixed `scene_units` frame. The installed CLI imported the bank in 0.177 seconds. Explicit full verification decoded every registered member in 0.358 seconds. On `h00`, the separate four-source residual-rule command queried `r001`, `r002`, `r000` and `r004` in that order. It read four photo/render pairs and produced 95,256 finite ranks in 0.268 seconds, including process startup and HTML generation. [Native external acceptance receipt](external.json)

Removing the real self-render for `r001` from a temporary copy made the full audit report `library_incomplete_or_unavailable` on all 95,256 pixels. The number of subset-gap and audited-absence claims was zero. A second check withheld the independent expected-depth verification. The scoring command exited with status 2. Structural inspection of a separate one-vertex PLY reported its vertex count and listed the camera, source membership, permission, RGB, camera-Z and opacity inputs required for scoring. Scoring the PLY also exited with status 2. Public materials contain numerical results, source IDs and content hashes. The ETH3D photos and image-based reports follow the study's private-data arrangement. [External acceptance receipt](external.json) · [Source rights](../rights.md)
