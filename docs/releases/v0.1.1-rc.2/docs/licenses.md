| Material | Included scope and provenance |
| --- | --- |
| Evidence Lens source and documentation | Original pure-Python scorer and grading tools in the wheel, user guide and specifications. NumPy and Pillow install separately under their own terms. |
| Fitted parameters | The project fitted the two logistic regressions and their preprocessing values against authored Blender error labels and prediction features. The threshold-selection and fit records are identified in the model index. |
| Authored demonstration | Project-authored tabletop RGB, calibrated cameras and a two-metre textured-plane projection with its scoring expectations. |
| Formal measurements | Selected aggregate numerical tables, identities and performance measurements. The archived scientific predictions were generated with SHARP and rendered with gsplat. |
