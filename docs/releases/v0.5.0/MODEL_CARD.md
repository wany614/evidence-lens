# Models on the v0.5 image grids

The default MS-L1 applies the released logistic coefficients to source/target comparisons. B-L1-transfer uses the primary source. MS-frozen and MS-ft combine the registered features and visual encoder with their released heads. The complete optional four-model archive is 164,854,827 bytes with SHA-256 `f555956840870309217cc85fe9b339ef53762679bbd2138b7f149d8ea451a7b7`. The retained MS-ft run used seed 1729 and 288 updates, changing 1,775,998 eligible backbone scalars. The release contains the full trained tensors, preprocessing and feature order. [Original training evidence and model IDs](../v0.3.0-rc.1/MODEL_CARD.md) · [Download the genuine weights](https://github.com/wany614/evidence-lens/releases/download/v0.3.0-rc.1/evidence-lens-cpu-v0.3.0-rc.1.zip)

The legacy route uses its original 252-square encoder input. The v2 route pads a registered analysis grid on its right and bottom to a multiple of 14. A 375 × 251 analysis image and a 378 × 252 analysis image share a 27 × 18 patch lattice. Their analysis supports remain distinct. The native square v2 route uses a 266 × 266 encoder input. [Reference encoder](https://github.com/facebookresearch/dinov2/blob/7764ea0f912e53c92e82eb78a2a1631e92725fc8/dinov2/models/vision_transformer.py) · [Frozen acceptance protocol](../../../protocol/v05-grid-acceptance.json) · [Official encoder numerical comparison](NEURAL_GRID.md)

All original thresholds are carried forward for descriptive comparison. The risk event is mean absolute display-sRGB difference across the three channels at an individual pixel, strictly greater than 0.05. The original two C6 profiles have no feasible threshold. An independent target photograph is required to estimate errors. Data and performance from original 256-square experiments retain their original scope. New layout comparisons respond to a single authored controlled scene. Stage A includes zero risk-model fits and zero threshold fits. [Original scientific results](../../general-closeout/README.md)
