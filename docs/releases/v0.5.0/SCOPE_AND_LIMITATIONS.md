# Interpretation and scope

The tool estimates photometric discrepancy for a prepared static reconstruction. Source self-renders, source observations, camera poses and native target predictions may enter scoring. Evaluators may open independent target observations after scores are sealed. A verified file hash establishes identity. Accuracy and its denominator require independent evaluation data.

The v1 prepared format retains the historical 256-square method. Five opt-in v2 shapes use their own crop and encoder contracts. A report may display larger raster images. Spatially local features and model ranking can change with analysis resolution. Reprojection assumes undistorted, zero-skew pinhole cameras and matching metric expected camera-Z. A real checkpoint is admitted on its parameter semantics and observed count within the format limit.

Two old T1 objects had genuine terminal probe failures at 16,251 and 17,199 Gaussians. They still account for all 48 missing fixed-layout scores out of 288 registered. The new checkpoint engineering test uses an already exposed object. Both old C6 profiles still have undefined adapted thresholds. Earlier speed and queue results describe their recorded 256-square hardware workloads.
