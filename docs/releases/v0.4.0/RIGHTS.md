|---|---|

| MS-L1 and B-L1-transfer operating parameters | Apache-2.0 for original project coefficients, preprocessing and thresholds. MS-L1 is included in the wheel. |

The included original executable scripts retain their Apache-2.0 notice. The asset manifests name their sources and versions. |
| CPU measurement ZIP | Original measurement tables, report and example output arrays from the two authorized authored scenes. The CC BY 4.0 grant covers the original research and example material. Its embedded table index, timing conditions and image origin permit independent checking. |
| Study protocols, numerical tables and prose | CC BY 4.0 for grantable original text and research records. Cite Evidence Lens and the DTU dataset when using the study. Source hashes and run IDs identify the private originals. |
| DTU photographs, crops, and image-based evaluation boards | Distributed by the data owner under the accompanying dataset terms. This release provides the retrieval and verification code, names, checksums, counts and numerical outcomes. Obtain the photos from the data owner for a local evaluation. |
| Upstream dependencies and runtimes | PyTorch, safetensors, NumPy, Pillow, gsplat, Blender and their components have their own licenses. The base CPU installation requires NumPy and Pillow. Rendering Gaussian assets uses a separately installed CUDA renderer. |
