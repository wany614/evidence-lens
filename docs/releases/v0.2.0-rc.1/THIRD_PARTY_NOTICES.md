# Third-party components

The two visual models contain parameters from Meta’s generic DINOv2 ViT-S/14. The registered revision is `7764ea0f912e53c92e82eb78a2a1631e92725fc8`. The original checkpoint is 88,283,115 bytes with SHA-256 `b938bf1bc15cd2ec0feacfe3a1bb553fe8ea9ca46a7e1d8d00217f29aef60cd9`. The frozen branch trains the Evidence Lens projection and risk head. The fine-tuned branch also changes two pretrained blocks and the terminal normalization. The upstream and project Apache notices are included in both model directories. [Meta’s license statement](https://github.com/facebookresearch/dinov2/blob/7764ea0f912e53c92e82eb78a2a1631e92725fc8/README.md#license) · [Upstream Apache text](licenses/DINOv2-LICENSE.txt) · [Original model download](https://dl.fbaipublicfiles.com/dinov2/dinov2_vits14/dinov2_vits14_pretrain.pth)

The CPU runtime installs PyTorch, NumPy, safetensors, Pillow and psutil from their own distributions. Each dependency retains the notices in its installed wheel. The registered formal research pipeline used Blender and SHARP. The example bundled here was created with the project's own textured-plane renderer. The formal publication carries the authorized quantitative measurements. [Asset-by-asset model and media inventory](licenses/ASSET-SCOPE.json)
