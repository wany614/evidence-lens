# Inspecting an image and its sources

Extract the viewer ZIP and open index.html. The six original bell views have four available synthetic source images. The fixed gallery image lets you inspect queries of 4, 8, 16, 32 and 128 sources. Open evaluation separately to see the independent reference and measured RGB error. The larger source package supplies originals and numerical data for inspection.
