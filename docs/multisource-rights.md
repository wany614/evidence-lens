# Rights for the multi-source study

The 16 worlds in this study are original static assemblies authored for Evidence Lens. The scene recipes specify each part, material, camera and light. The reference renderer consumes those recipes. The optimizer receives two or four source RGB images and calibration. Each world starts from the same procedural Gaussian initialization. The public example is the first registered development family, the offset bell cage (scene 057).
