## DTU MVS SampleSet

DTU provides the SampleSet for evaluating multi-view stereo. Its bundled ReadMe calls the data citeware and requests citation of Rasmus Jensen, Anders Dahl, George Vogiatzis, Engin Tola and Henrik Aanæs, “Large Scale Multi-view Stereopsis Evaluation,” CVPR 2014. The D1 research archive retains the ReadMe and hashes. The public repository publishes original adapter code, acquisition instructions, identifiers and measurements. The photographs, crops, derived image boards, reference scans and supplied MATLAB implementation stay in the private research archive. Obtain the inputs directly from DTU. [Official data and conditions](https://roboimagedata.compute.dtu.dk/?page_id=36) · [Research paper](https://openaccess.thecvf.com/content_cvpr_2014/papers/Jensen_Large_Scale_Multi-view_2014_CVPR_paper.pdf)
