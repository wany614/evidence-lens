# Four frozen methods on the offset bell cage

Each report covers the same six predicted cameras and 393,216 native pixels from the four-source original development reconstruction. Choose a model to inspect its continuous risk, original cutoff states and per-pixel unknown reasons. HTML files are self-contained and can be opened offline.

| Model and report | Source evidence used for scoring | Low | High | Unknown |
| --- | --- | ---: | ---: | ---: |
| [MS-L1](MS-L1.html) | Four sources, fitted linear model | 316,145 | 72,213 | 4,858 |
| [MS-ft](MS-ft.html) | Four sources and the fine-tuned visual model | 325,516 | 62,842 | 4,858 |
| [MS-frozen](MS-frozen.html) | Four sources and the frozen-encoder visual model | 322,577 | 65,781 | 4,858 |
| [B-L1-transfer](B-L1-transfer.html) | Registered primary source and the historical single-source model | 175,247 | 217,969 | 0 |

The original thresholds differ between methods. The two neural methods preserve their Stage B initialization history and Stage C fitted weights. These counts describe coverage at those cutoffs. The released archive also contains both helical-beads layouts, the two-source bell example and a grader for a new CPU installation.
